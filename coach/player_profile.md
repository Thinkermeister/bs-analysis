# 選手カルテ — Recursion（ScoreSaber / BeatLeader 76561199083982597）

## 1. 環境

- 【申告】Quest 2 単体でプレイ。Steam 版も持っている。
- 【申告】持ち方は claw grip（人差し指と中指でコントローラーを握り込む）。手の甲側のストラップはこの角度では固定できない。
- 【申告】コントローラーは単4エネループ＋アダプターで軽量化。グリップにスポンジや滑り止めテープ。
- 【申告】Quest 標準のストラップを締めると指の握りが緩められ、引っかけるだけでよい場面が増えた。ただし固定するほど締めると可動域が狭まり軌道がおかしくなる。
- 【申告】左利き寄りの両利き。ワンハンド譜面は左利き設定にするとスコアが上がる。
- 【申告】プレイ場所の都合でスクワットの多い譜面はやりにくい。
- 【申告】立ち位置はノーツにかなり近い。
- 環境の変更履歴は [`changelog.md`](changelog.md)。

## 2. 実力の位置と目標

- 【申告・記録】境界は ScoreSaber ★3。
  - ★0〜2：残っている譜面はすべてフルコン済みで、精度だけが足りない。
  - ★3：未達のほとんど（約94%）はフルコン済み。精度が課題。
  - ★4：フルコンできていない譜面が多い。フルコンできれば大半は93%に届く。
  - ★5：未達はすべてフルコン未達。
- 【申告】目標：★3以下は精度を上げる。★4以上は、精度に気を配れるくらい楽にフルコンできるようになる。
- 【申告】体感では ScoreSaber の★は BeatLeader の★より1つ上の難しさ。
- 【申告】実況していた時期はリクエスト（いたずらのリクエストを含む）で遊んだ曲が多く、それが今の平均精度を下げていると考えている。今やり直しても少ししか上がらない見込み。
  - 分析上の注意：その時期の記録には「選んでいない・練習していない曲」が多く混ざる。弱点の分析では、実況期間の記録を分けるか、何度も遊んだ曲・最近の記録に絞って確かめる（実況期間の日付は未記録）。

## 3. 強み

- 【記録】★3までのフルコン率が高い。★3の未達160譜面のうち、フルコン未達は11譜面だけ。
- 【記録】ゆっくりした譜面は強い。★3で密度1.5ノーツ/秒未満なら約80%が96%に届いている。
- 【記録】左手の精度は右手より1振りあたり約1点高い（BeatLeader の手別データ）。
- 【記録】ノーツの速さ（NJS）が10以下の遅めの譜面は、★3で71%が96%に届いている（全体平均より高い）。

## 4. 弱点（克服したときの効果が大きい順）

数字は ★3 の未達譜面のうち、その弱点が解消すれば届く見込みのある譜面数の粗い推定。要因は重なるので足し算はできない。

1. **右手の精度**（約49譜面）
   - 【記録】左手より1振りあたり約1点低い。左手並みになれば全体で約+0.45%。
   - 【申告】練習で右が1点上がれば左も1点上がるはずで、左右差そのものは縮まらないかもしれない。
2. **同じ手の速い切り返し（「おいでおいで」）**（約42譜面）
   - 【申告】縦・横・斜めを問わず、速い繰り返しの逆方向連続に弱い。速い曲では早めに振ってしまう。
   - 【記録】★3で、速い切り返しが無い譜面は61%が届く。1〜10%含む譜面は31%、10〜30%含む譜面は22%。
   - 【記録】密度2.5ノーツ/秒あたりに壁がある。★3の到達率：1.5未満80%、2.5〜3は25%、3.5超は5%。
3. **手が中央を越える配置（クロス・反対レーン）**（約26譜面）
   - 【記録】★3・密度2〜3ノーツ/秒の譜面で、中央越えが10%以上だと17%、10%未満だと67%が届く。速さとは別に効いている。
4. **平行外側切り（両手同時に外向きへ真横に切る）**（2026-11-25 追加）
   - 【申告】どれも精度が低い自覚がある。
   - 【記録】★3で、この配置を含む譜面は含まない譜面より到達率が低い。密度2ノーツ/秒未満：50%対86%。2〜3ノーツ/秒：23%対50%。数回出てくるだけでも差が出る。★3の未達譜面のうち27譜面に含まれる。
   - 【仮説】同時押しの多い譜面はほかの面でも難しい可能性があり、譜面単位の比較だけでは切り分けきれていない。ノーツ単位の確認には BeatLeader の1ノーツごとの記録が必要。
5. **最下段からの切り上げ**（約8譜面）
   - 【記録】弱い傾向がある。
6. **同じ拍・同じ色の2ノーツ（振り抜く側の精度）**（★3では約1譜面）
   - 【申告】特に苦手なのは、端のレーンで下から上へまっすぐ切り上げる縦のスタックと、対角から始まる離れた2つを斜め下から切り上げる形。
   - 【申告】スライダー譜面とチェインノーツはまだ攻略できていない。
7. **ワンハンド譜面**
   - 【申告】左利き設定にすれば上がると把握済み（★3には該当なし）。

## 5. まだ確かめていないこと・仮説

- 【記録→仮説】**外側のレーン（いちばん左・いちばん右の列）が多い譜面**で落としている（2026-11-25、カンナムスタイルの指摘から発見）。
  - ★3・密度2〜3ノーツ/秒：外側レーン30%未満は72%、30〜40%は41%、40%以上は31%が届く。密度2未満でも40%以上は67%（ほかは82〜85%）。
  - 手を大きく広げる・腕を伸ばす動きに弱い可能性。平行外側切りとも関係しているかもしれない。
- 【記録】同じ向きに続けて振る（振り戻しが要る）配置は、★3全体では到達率との関係がはっきりしなかった。

- 【記録→仮説】ノーツの速さ（NJS）が速い譜面ほど落としている。★3・密度2〜3ノーツ/秒の譜面で、NJS 13以下は57%、NJS 13〜16は32%が届く。
  - 【申告】長い曲の後半や、ノーツが直前に現れる譜面はほぼ反射で切っている。
  - JDFixer で反応時間を長めに固定したあと、この差が縮まるかで確かめる（変更日は changelog に記録する）。
  - 例：Lichen Hard（NJS 4 の極端に遅い譜面）は 92.3% でフルコン未達、同じ長さの Normal（NJS 7）は 97.5% FC。遅すぎる側にも問題があるかもしれない。
- 【申告】3分半以上の長い曲は集中力が切れる。→ 未検証（曲の長さで平均精度にははっきりした差が出ていない）。
- 【申告】短い曲は精度が取れない。→ 未検証（平均精度では差なし。ばらつきは未確認）。
- 【申告】直前に出現する・方向が変わるノーツ。→ ゲームの距離設定（JD/反応時間）次第なので、設定を記録してから比べる。
- スクワットの多い譜面 → 壁のデータが未取得。
