# 環境・設定の変更履歴

変更の前後で記録を比べるための基準日。新しいものを上に書く。
値が分からないものは「未記録」とし、分かったら書き足す。

## 2026-11-25

- **Quest 版 Beat Saber を 1.37 → 1.40.8 に更新**（ModsBeforeFriday）。
  - Meta ストアの配信チャンネルを LIVE に戻してから、MBF で 1.40.8 を選んでダウングレード・mod 化した。
  - mod はすべて入れ直し。BeatLeader・JDFixer・HitScoreVisualizer・Qounters++ など。
  - ScoreSaber は ScoreSaber 2 対応版を別途導入。
- **Saber Tailor がなくなった**（1.40.8 版が無い）。
  - それまでセイバーの長さを約115%に伸ばしていた。当たり判定は伸ばさない設定なので見た目だけの変化で、位置・角度の補正はしていなかった。
  - 角度を変えたくなったら EasyOffsetQuest（PC 版 Easy Offset のプリセットも読める）。
- **JDFixer**：導入済み。反応時間（RT）や JD の値は未記録。
  - 変える場合は NJS は変えない（NJS を変えると記録が送信されない）。
- **練習リストを開始**：「練習 SS ★3重点 96%以下」「練習 SS Claude推薦 基準以下」（GitHub bs-playlists）。
