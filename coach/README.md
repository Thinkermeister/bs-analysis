# coach/ — Claude のコーチング記録

Beat Saber（Quest 版）のプレイ記録から分かったことを、Claude が書きためていく場所。
GPT との分析（リポジトリ直下の `public/`・`summary/`）とは別に置いている。

| ファイル | 中身 |
|---|---|
| [`player_profile.md`](player_profile.md) | 選手カルテ。環境・目標・強み・弱点・仮説を、分かった時点で書き換えていく「現在の結論」 |
| [`changelog.md`](changelog.md) | 環境や設定を変えた日付の記録。変更の前後で記録を比べるときの基準日になる |
| [`findings/`](findings/) | 分析ごとの記録（日付つき）。数字・方法・限界をそのまま残す |
| [`data/`](data/) | 分析に使った特徴量つきの表（CSV） |
| [`tools/`](tools/) | 譜面ファイルから特徴量を計算するスクリプト |

## 書き方の約束

- カルテは「今の結論」。古い結論は消さずに、変わった理由と一緒に `findings/` に残す。
- 本人の自己申告と、記録から分かったことを区別して書く（【申告】【記録】【仮説】）。
- 精度の基準（届いたかどうか）は ScoreSaber ★0〜2：97%、★3：96%、★4：93%、★5：90%。
- 数字には、どのデータで何譜面を比べたかを添える。

## 特徴量の定義（tools/feat2.py と tools/bsfeat.js は同じ定義）

| 列 | 意味 |
|---|---|
| `nps` | ノーツ数 ÷ 最初から最後のノーツまでの秒数 |
| `sps` | 振りの回数/秒（同じ手で1/16拍未満に並ぶノーツは1振りとみなす） |
| `njs` | ノーツの飛んでくる速さ（譜面の設定値） |
| `cross` | 手が中央を越える配置の割合（左手ノーツが右2レーン／右手ノーツが左2レーン） |
| `frev` | 同じ手で0.3秒未満に135°以上向きを変える振りの割合（速い切り返し・「おいでおいで」） |
| `fast` | 同じ手の振り間隔が0.25秒未満の割合 |
| `bup` | 最下段で上向き（上・左上・右上）に切るノーツの割合 |
| `sbsc` | 同じ拍・同じ色に2つ以上あるノーツの割合（スタック・スライダー・ウィンドウ） |
| `outward_horiz_pairs` | 同じ拍に左手が真左・右手が真右へ切る組の数（平行外側切り） |
| `left` | 左手ノーツの割合 |
